# Feature inventory — the Great Merge (Phase 0)

The client's feature set lives in the extension (`tools/ext/t2r-ext.c`, a unity build that
`#include`s 156 sibling modules on `main` after build 201 (154 after build 191); this branch's
`tools/ext` at the split had 135). The Great Merge ports each **feature** into `mod/` source — the C
is the behavioural reference, not the code being moved. This file is the control surface: one row
per module, its domain, its dependency footprint, its `t2r-*.txt` toggles and where the mod already
overlaps.

Generated by `mod/scripts/gen-features.py` from the ext's include list + `tools/ext/GENERATED.md`.
Domain / overlap / status maps are curated by hand. The build-191 and build-199/200/201 rows below
were added by hand from `git show main:tools/ext/t2r-ext.c` / `main:tools/ext/GENERATED.md`:
re-running the generator here would read this branch's older ext and drop them.

**Branch state (2026-11-21).** The port work in this tree is committed on `desloppify/code-health`
(`7e4572c`, netsmooth + opcodes + melee timing; `5c47def`, localisation support; `4248c97`, the
backpack composed-bag seam; earlier `UNTESTED:` commits port the rest). It is **not merged** into
`main`. `main` has advanced with the `Port build 191: …` commits (`a1aa3e5`,
`95597a4`, `5ee40f6`, `fb5e6eb`) which add **19 new direct ext modules** (plus 3 nested
`customize_*.c` modules), 12 new headers, six new private generated headers, 186 new `t2r-*.txt`
strings and regenerated Polish tables (`12-customize`, `13-achievements`, …). The inventory below
**includes** that build-191 work; rows flagged `build 191:` mark features already ported here that
gained new work on `main`. Do **not** attempt the merge or re-run the generator here: the ext
(`snake_case`) and mod (`PascalCase`, `g_camelCase`) codebases differ so widely in casing that a
text merge is not tractable. Build 191 stays a separate behavioural reference; port individual
behaviours into `mod/` as with the rows below. No ext cutover / toggle was flipped.

`main` has since advanced through **build 199/200/201** (`66db11f`, `3e0b498`, `66fdfc6`,
`5f8a9da`, `abffae7`, `59902b9`, `256a5ac`): two more direct modules (`chat.c`, `loadheap.c`),
two pure C cores (`chat.h`, `padact.h`), two offline tests, seven more private generated headers
and new `t2r-*.txt` strings (1,743 distinct names in main's ext vs 1,638 here). Those rows and the
reworked features are inventoried below;
nothing in that batch is ported here, no `t2r-*.txt` gate was flipped in this tree and no ext wire
ID was renumbered.

**Legend** — `Pri`: P1 first … P5 last. `Deps`: mechanism tags the module uses (`net`, `audio`, `widget`, `camera`, `pad`, `hook`) plus `data` when it needs generated headers. `Toggles`: count of `t2r-*.txt` switches the module reads. `Mod overlap`: existing mod code the port should extend. `Status`: `not started` / `in progress` / `ported` / `dropped`.
